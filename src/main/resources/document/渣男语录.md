# 渣男语录

## 一、分手推责类

**“你要这样想，我也没办法。”**
——翻译：算了，反正都被你发现了，干脆闭嘴。万能甩锅句式，把沟通失败的责任全部推给对方。

**“你很好，我不配，不要为我流眼泪。”**
——翻译：分手不是因为不合适，而是权衡之下你是比较容易分的那一个。话说得模棱两可，实际是想把你发展成鱼塘里的一员。

**“我配不上你，怕耽误你。”**
——翻译：我既不想对你好，也不想对你负责，先给你打个预防针方便甩锅。

**“我早就不爱你了，只是不知道怎么和你说。”**
——翻译：其实早就想分了，只是一直在等一个成本最低的时机。

**“彼此冷静一段时间吧。”**
——翻译：我想分手了，别烦我了，你自己慢慢接受分手事实吧。

**“其实，我没有你想的那么好。”**
——翻译：提前给你打预防针，这样以后我做出任何烂事，你都不能怪我，因为我早就“提醒”过你了。

**“从一开始我就知道，我们走不到最后。”**
——翻译：既然早就知道，为什么还要开始？因为享受你付出的过程比你的感受重要。

**“你就当从没遇见过我吧。”**
——翻译：我连体面分手的耐心都没有，最好你从我的世界里彻底消失，别来烦我。

**“我妈不同意我们在一起。”**
——翻译：我妈可能根本不知道你的存在。搬出家人是最省事的借口，不用自己当坏人。

**“我们还可以当朋友啊，我不想失去你。”**
——翻译：当朋友的意思是，我还想保留随时联系你、找你帮忙、甚至偶尔暧昧的权利，但不用对你负任何责任。

## 二、敷衍冷淡类

**“我最近真的特别忙。”**
——翻译：你的事排在我所有事后面。他不是没时间，只是你不值得他花时间。

**“多喝热水。”**
——翻译：我不想花心思关心你，但直接说“不关我事”太难看，所以给你一句万能废话。

**“我怕你生气才没告诉你。”**
——翻译：我知道做了会让你生气的事，但我选择瞒着你。现在被发现了，就把锅甩给你，怪你“太容易生气”。

**“你能不能成熟一点？”**
——翻译：我对你已经没耐心了，你最好懂事一点别来烦我。

**“别闹了，你以前不是这样的。”**
——翻译：你以前很好骗，现在怎么开始有要求了？这句话的目的是让你怀疑自己，觉得“变了的”是你。

**“我今晚打算早点睡。”**
——翻译：我今晚不想理你，别给我发消息了，我要去做别的事，但不想跟你解释。

**“我错了，行了吧。”**
——翻译：我已经没耐心了，你能不能别吵了。这句话里的“行了吧”三个字，比任何脏话都伤人。

**“你先给我打一千，情人节礼物明年给宝贝补上。”**
——翻译：我不打算为你花钱，但我想让你为我花钱。用“明年补上”这种永远兑现不了的承诺来搪塞。

## 三、经典万能句

**“我只是犯了所有男人都会犯的错误。”**
——翻译：我出轨了，但我不想认错，拉全体男性下水给自己找台阶。

**“我跟她只是普通朋友。”**
——翻译：她是我的备用供给源，我得把这个人留在身边，两个人同时为我争风吃醋的感觉真不错。

**“那你想怎么办？我还能怎么办？”**
——翻译：我不想解决问题，我只想让你闭嘴。把问题抛回给你，让你觉得自己在无理取闹。

**“我从来没有百分百投入过。”**
——翻译：早就给自己留好了退路，分手的时候可以理直气壮地说“我从没骗过你”。

**“她主动的，我也没办法。”**
——翻译：把所有责任推给第三方。说得好像自己毫无选择，实际上从来没有拒绝过。

**“你要是温柔体贴懂事，我怎么会劈腿呢。”**
——翻译：出轨是你的错，因为你不符合我心目中的“完美女友”标准。把背叛包装成“被迫无奈”。

**“我跟别人聊骚是不对，但你看我的手机更不对。”**
——翻译：我犯错可以，但你不能发现。道德绑架的极致，让受害者觉得自己才是做错事的那个人。

**“我不喜欢秀恩爱。”**
——翻译：我朋友圈里有别的鱼，别耽误我继续钓。

**“男人都忘不了初恋的。”**
——翻译：我拿前任当挡箭牌，你凭什么不包容我？用“深情”做幌子，实际上是对现任的极度不尊重。

**“我也不想跟前任打游戏啊，我朋友拉的啊。”**
——翻译：我和前任还有联系，但我不想承认是我主动的。把责任推给“朋友”，把自己包装成无辜的受害者。
